# Katalog Roboczo-Eksperymentalny Aether

Katalog ten pełni funkcję głównej przestrzeni roboczej (sandboxa) do bezpiecznej wymiany plików, przechowywania artefaktów i przeprowadzania operacji I/O przez system Aether.

## Cele

1. **Przestrzeń wymiany danych (I/O):**
    Pliki z zewnątrz, logi, konfiguracje i zasoby, które użytkownik chce poddać mojej analizie (Aether), powinny być umieszczane tutaj.

2. **Bezpieczny poligon doświadczalny (Sandbox):**
    Prototypy, wersje robocze skryptów (PoC) oraz eksperymentalny kod. Wszelkie testowe iteracje powinny odbywać się w `workspace/` do czasu zatwierdzenia przeniesienia ich do głównych modułów (np. `backend/`, `frontend/`).

3. **Tymczasowe raporty i artefakty (Outputs):**
    Domyślna lokalizacja zapisu dla obszernych zestawień, analiz logów, przeformatowanych struktur bazy i wszelkich generowanych przeze mnie raportów tekstowych lub danych ustrukturyzowanych, o które poprosi użytkownik.
