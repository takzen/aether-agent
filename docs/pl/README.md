# Indeks Dokumentacji Aether

Ten folder zawiera dokumentację techniczną dla Agenta Aether.

## Podstawowe Dokumenty

1. `API.md` - referencje REST API
2. `ARCHITECTURE.md` - architektura backendu/frontendu/danych
3. `CHANGELOG.md` - historia wydań
4. `COGNITION.md` - persona, autonomia i zachowanie kognitywne
5. `COMMANDS.md` - komendy ukośnikowe i zachowanie terminala
6. `FEATURES.md` - główne możliwości produktu
7. `PROJECT_CORE_X.md` - notatki systemowe na poziomie projektu
8. `TESTING_EVALUATION.md` - instrukcja testów ewaluacyjnych backendu
9. `WORKFLOW_CORE_X.md` - notatki dotyczące przepływów pracy operacyjnych

## Uwagi

-   Preferuj kodowanie UTF-8 dla wszystkich dokumentów.
-   Utrzymuj synchronizację dokumentów punktów końcowych z `backend/main.py`.
-   Utrzymuj synchronizację dokumentów tras UI z `frontend/src/app`.
